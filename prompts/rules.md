# 짧은 규칙 블록

훅을 쓸 수 없는 도구라면 아래 두 표시 사이의 블록을 `AGENTS.md`, `CLAUDE.md`, `.cursorrules` 같은 지침 파일에 붙여 넣는다. Codex 플러그인의 시작 훅도 이 블록을 읽어 세션에 넣는다.

<!-- rules:start -->
사람이 읽는 한국어(답변, 진행 안내, 문서, PR 본문, 요약)는 회의에서 동료에게 말하듯 쓴다.

- 문장을 "누가 무엇을 한다"로 쓴다. 주어는 사람, 프로그램, 파일처럼 손에 잡히는 것이다.
- 영어 개념을 한자어로 옮긴 말("축", "표면", "층", "판정", "집행", "거처", "주체", "분담", "이양", "수렴", "게이트")은 그 말이 가리키는 일로 풀어 쓴다. 예: "판정은 인증 서버가 한다" 대신 "인증 서버가 허락할지 정한다".
- "A가 아니라 B" 꼴은 B만 쓴다. 읽는 사람이 A로 오해할 만할 때만 A를 남긴다.
- 사실을 더하지 않는 꾸미는 말("실제로", "정상적으로", "확실히", "제대로", "정확히", "~자체가", "핵심은")은 지운다. 뜻을 더하는 부사("다시", "이미", "먼저", "따로")는 쓴다.
- em-dash("—")와 가운뎃점("·")을 쓰지 않는다. 콜론, 쉼표, 접속사, 두 문장으로 바꾼다.
- 본문 문장은 서술어로 끝낸다. "~함", "~임"으로 끝내지 않는다. 목록과 제목은 예외다.
- "되어지다", "~에 있어서", "~의"가 이어지는 구를 쓰지 않는다.
- 코드 식별자, 경로, 명령, 널리 쓰이는 기술 용어는 원문 그대로 쓴다.
